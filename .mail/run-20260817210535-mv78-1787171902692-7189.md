**Implementation:**
- Direct Unix datagram socket communication
- No libsystemd dependency (pure Rust)
- Compliant with freedesktop.org sd_notify(3) spec

**Public API:**
```rust
pub fn notify_ready() -> Result<()>           // READY=1
pub fn notify_status(msg: &str) -> Result<()> // STATUS=...
pub fn notify_stopping() -> Result<()>        // STOPPING=1
pub fn notify_mainpid(pid: u32) -> Result<()> // MAINPID=...
pub fn notify_watchdog() -> Result<()>        // WATCHDOG=1
pub fn is_systemd() -> bool                   // NOTIFY_SOCKET check
```

**Protocol Details:**
- Socket: Unix datagram (SOCK_DGRAM, unbound)
- Path: $NOTIFY_SOCKET (set by systemd)
- Format: newline-separated key=value pairs
- Abstract namespace: @ prefix → \0 conversion
- Graceful: No error if NOTIFY_SOCKET unset

**Core Implementation:**
```rust
pub fn notify(state: &str) -> Result<()> {
    let socket_path = env::var("NOTIFY_SOCKET")?;
    
    // Handle abstract namespace (@/run/systemd/notify)
    let socket_path = if socket_path.starts_with('@') {
        format!("\0{}", &socket_path[1..])
    } else {
        socket_path
    };
    
    let socket = UnixDatagram::unbound()?;
    socket.send_to(state.as_bytes(), &socket_path)?;
    
    Ok(())
}
```

### Architecture

**Socket Communication Flow:**
```
Daemon                    systemd
  |                          |
  | env::var("NOTIFY_SOCKET")
  |<-------------------------|
  |                          |
  | UnixDatagram::unbound()  |
  |------------------------->|
  |                          |
  | send_to("READY=1")       |
  |------------------------->|
  |                          |
  |      (marks active)      |
  |                          |
```

**Abstract Namespace:**
- Normal path: `/run/systemd/notify`
- Abstract path: `@/run/systemd/notify`
- Abstract → memory-only (no filesystem entry)
- Conversion: `@` → `\0` (null byte prefix)

**Error Handling:**
- NOTIFY_SOCKET unset → Ok(()) (silent success)
- Socket creation fail → Err (report to user)
- Send fail → Err (report to user)
- All errors logged via tracing
