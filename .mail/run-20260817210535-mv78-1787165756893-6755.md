## Build Pipeline (Per Platform)

**1. Prerequisites Installation:**
- Ubuntu: `apt-get install protobuf-compiler`
- macOS: `brew install protobuf`
- Windows: `choco install protoc`

**2. Platform Verification:**
- Windows: ConPTY availability check (build 17763+)
- Linux: Ubuntu 22.04 LTS verification
- macOS: macOS 13 verification via sw_vers

**3. Code Quality Checks:**
- `cargo fmt --all -- --check` (formatting)
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`

**4. Build Verification:**
- Debug build: `cargo build --workspace --all-features`
- Release build: `cargo build --workspace --all-features --release`

**5. Testing:**
- Unit tests: `cargo test --workspace --lib --all-features` (all platforms)
- Integration tests: Windows only (PTY abstraction pending in Phase 3 Week 1-2)

**6. CI Summary:**
- Aggregates results from all platforms
- Reports pass/fail status for each OS
