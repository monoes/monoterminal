### Q2: Sender Comparison Strategy (7 errors E0277)

**Decision**: ✅ **Remove equality checks, compare by session ID / client ID instead**

**Rationale**:
- mpsc::Sender does NOT implement PartialEq by design
- Channels are identified by their endpoints, not comparable by value
- Tests should verify session/client relationships, not channel equality

**Fix Pattern**:
```rust

// RIGHT (works):
assert_eq!(session.session_id, expected_session_id);  // Compare IDs
assert_eq!(session.client_id, expected_client_id);
// OR: Just verify sender is Some/None

```
