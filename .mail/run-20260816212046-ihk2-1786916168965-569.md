### crates/master/src/main.rs
```rust
// Enhanced tracing initialization (lines 39-65)
if std::env::var("SOAK_TEST_MODE").is_ok() {
    // JSON logs to hourly-rotated files
    let file_appender = tracing_appender::rolling::hourly("./soak-logs", "monoterminal.log");
    let (non_blocking, _guard) = tracing_appender::non_blocking(file_appender);

    tracing_subscriber::fmt()
        .json()
        .with_current_span(false)
        .with_writer(non_blocking)
        .init();

    Box::leak(Box::new(_guard));  // Guard lives for program lifetime
} else {
    // Normal mode: compact console output
    tracing_subscriber::fmt()
        .with_target(false)
        .compact()
        .init();
}
```

## Analysis Capabilities (New)

### 1. Crash Investigation

**Scenario:** External monitor shows crash at 18:45.

**Query JSON logs for exact moment:**
```powershell
Get-Content .\soak-logs\monoterminal.log.2026-08-16-18 |
    ForEach-Object { $_ | ConvertFrom-Json } |
    Where-Object { [datetime]::Parse($_.timestamp) -ge "2026-08-16T18:44:00" } |
    Format-Table timestamp, level, message -AutoSize
```

**Find:**
- Last error before crash
- Which module failed (`target` field)
- Exact timestamp (microsecond precision)

### 2. Pattern Detection

**Count session operations:**
```python
import json
import glob

logs = []
for file in glob.glob("soak-logs/monoterminal.log.*"):
    with open(file) as f:
        logs += [json.loads(line) for line in f]

session_creates = [log for log in logs if 'create_session' in log['fields']['message']]
print(f"Sessions created: {len(session_creates)}")  # Should be ~2880 for 24h (10 per 5 min)
```

### 3. Error Timeline

**Extract all errors:**
```powershell
Get-Content .\soak-logs\*.log.* |
    ForEach-Object { $_ | ConvertFrom-Json } |
    Where-Object { $_.level -eq "ERROR" } |
    Export-Csv -Path "error-timeline.csv" -NoTypeInformation
```

Import `error-timeline.csv` into Excel → Timeline chart showing error bursts.

### 4. Correlation with External Metrics

**Merge external metrics with log events:**
```python
import pandas as pd

# Load external metrics
metrics = pd.read_csv("external-metrics-*.csv")
metrics['Timestamp'] = pd.to_datetime(metrics['Timestamp'])

# Load JSON logs
logs_df = pd.DataFrame(logs)
logs_df['timestamp'] = pd.to_datetime(logs_df['timestamp'])

# Merge on timestamp (nearest minute)
merged = pd.merge_asof(
    metrics.sort_values('Timestamp'),
    logs_df[logs_df['level'] == 'ERROR'].sort_values('timestamp'),
    left_on='Timestamp',
    right_on='timestamp',
    direction='nearest',
    tolerance=pd.Timedelta('1min')
)

# Find errors that occurred during memory spikes
spikes = merged[merged['MemoryGrowth%'] > 8.0]
print(spikes[['Timestamp', 'MemoryGrowth%', 'message']])
```
