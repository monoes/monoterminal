## Fixes Applied

### Error 1 (Line 424): render() method - Overlapping Borrows

**Problem:**
```rust
let queue = self.queue.as_ref()?;  // Immutable borrow
let vertices = self.build_vertices(perf)?;  // ERROR: Needs mutable borrow
queue.write_buffer(...);  // Uses immutable borrow
```

**Fix:** Reordered operations - all mutable work BEFORE immutable borrows
```rust
// Step 1: Mutable work (process PTY, build vertices)
self.process_pty_output(perf)?;
let vertices = self.build_vertices(perf)?;

// Step 2: Immutable borrows (GPU resources)
let queue = self.queue.as_ref()?;
let surface = self.surface.as_ref()?;
// ... use queue, surface immutably
```

**Pattern:** Classic "split borrow scope" fix - separate mutable and immutable phases

### Error 2 (Line 532): build_vertices() method - Iterator Borrow

**Problem:**
```rust
let dirty_region = self.terminal_grid.dirty_region();
for (row, col) in dirty_region.iter_dirty() {  // Immutable borrow active
    let glyph_info = self.ensure_glyph_cached(key)?;  // ERROR: Needs mutable
}
```

**Fix:** Collect iterator into Vec - consumes iterator, releases borrow
```rust
// Collect dirty cells (consumes iterator, releases borrow)
let dirty_cells: Vec<_> = self.terminal_grid.dirty_region()
    .iter_dirty()
    .filter_map(|(row, col)| {
        self.terminal_grid.get_cell(row, col).map(|cell| (row, col, *cell))
    })
    .collect();  // Borrow ends here

// Now process (mutable borrow allowed)
for (row, col, cell) in dirty_cells {
    let glyph_info = self.ensure_glyph_cached(key)?;  // OK
}
```

**Pattern:** Classic "collect to break borrow" fix - no clones, efficient
