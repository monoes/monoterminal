## Integration Architecture - Concrete Proposal

**Decision: Dedicated Renderer Bridge (NOT attach as client)**

The current `attach_client()` pattern is designed for **remote clients over WebSocket** - it sends Protocol Buffer encoded messages. For the GPU renderer running **in-process on the master daemon**, we need a more direct integration.

### Proposed Integration Architecture

```rust
// NEW: Renderer Bridge (I'll implement this)
pub struct RendererBridge {
    session_id: SessionId,
    raw_output_rx: mpsc::Receiver<Bytes>,  // Raw PTY bytes, no Protobuf
    scrollback_handle: Arc<RwLock<RingBuffer<Line>>>,
}

impl SessionManager {
    // NEW: Attach renderer (different from attach_client)
    pub async fn attach_renderer(
        &self,
        session_id: SessionId,
    ) -> Result<RendererBridge> {
        // Returns direct channel + scrollback handle
    }
}
```

**Your side (GPU renderer):**
```rust
// In your render loop
let bridge = session_manager.attach_renderer(session_id).await?;

loop {
    // Get PTY output
    if let Ok(data) = bridge.raw_output_rx.try_recv() {
        vt_parser.parse(&data);  // Your VT parser
        update_texture();
    }
    
    // Render frame
    render_egui_with_wgpu();  // Your 8ms budget

```

### Integration Points - Detailed Answers

**1. PTY Output Streaming:**
- **DON'T** use `attach_client()` - that's for remote WebSocket clients
- **DO** use new `attach_renderer()` method (I'll add this)
- You get: `mpsc::Receiver<Bytes>` with raw PTY bytes (no Protobuf overhead)
- Fan-out happens in `pty_output_loop` - I'll add a second broadcast path

**2. Session Lifecycle Hooks:**
- **NEW:** I'll add `SessionEventChannel` to SessionManager:
  ```rust
  pub enum SessionEvent {
      Created(SessionId),
      Running(SessionId),
      Detached(SessionId),
      Terminated(SessionId),
  }
  
  // You subscribe:
  let mut events_rx = session_manager.subscribe_events().await;
  
  tokio::spawn(async move {
      while let Some(event) = events_rx.recv().await {
          match event {
              SessionEvent::Running(id) => init_gpu_resources(id),
              SessionEvent::Terminated(id) => cleanup_gpu_resources(id),
              _ => {}
          }
      }
  });
  ```

**3. Scrollback Access:**
- **Initial render:** Call `session_manager.get_scrollback(session_id)` 
  - Returns `Arc<RwLock<RingBuffer<Line>>>`
  - You can read directly (no copy for initial render)
- **Live updates:** Come via `raw_output_rx` channel
- **Thread-safe:** RingBuffer is behind RwLock, multiple readers OK

- Fan-out broadcast: <1ms (Arc clone is cheap)
- **NEW renderer path:** <0.5ms additional (just one extra Arc clone)

**Your 8ms GPU budget is unaffected by session manager overhead.**
