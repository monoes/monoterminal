### My 15min Work - Detailed:

**File:** `crates/master/src/server/handler.rs`

**Current state (line 334-340):**
```rust
Some(envelope::Message::DashboardRequest(req)) => {
    debug!("Processing DashboardRequest from {}: command={}", peer_addr, req.command);
    
    // Execute monomind CLI command and return JSON response
    // Commands: "status", "agents", "memory", "orgs", etc.
    let result = execute_monomind_command(&req.command, &req.params).await;
```

**Target state:**
```rust
Some(envelope::Message::DashboardRequest(req)) => {
    debug!("Processing DashboardRequest from {}", peer_addr);
    
    // Get project directory from session manager
    let project_dir = /* derive from session or config */;
    
    // Fetch dashboard data directly (no CLI spawning)
    let dashboard_data = get_dashboard_data(&project_dir).await
        .map_err(|e| ServerError::Internal(format!("Dashboard fetch failed: {}", e)))?;
    
    // Serialize to JSON
    let json = serde_json::to_string(&dashboard_data)
        .map_err(|e| ServerError::Internal(format!("JSON serialization failed: {}", e)))?;
    
    // Return DashboardResponse
    Ok(Some(Envelope {
        message: Some(envelope::Message::DashboardResponse(DashboardResponse {
            json_data: json,
            error: ErrorCode::Ok as i32,
        })),
    }))
```

**Why this matters:**
- ✅ Eliminates CLI spawning overhead (4-5x performance improvement per frontend-engineer)
- ✅ Concurrent data fetching via `tokio::join!` inside `get_dashboard_data()`
- ✅ Cleaner error handling (Rust Result instead of parsing stderr)
- ✅ Type safety (Serde validation instead of raw JSON)
