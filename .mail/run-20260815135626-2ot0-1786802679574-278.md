**2. Handler Wire-Up (4 Message Types)**

Location: `crates/master/src/server/handler.rs` lines 18-290

**Implemented:**

✅ **AttachRequest** (lines 135-185)
- Parse session_id UUID from request
- Create mpsc channel (256 msg buffer)
- Register client with SessionManager.attach_client()
- Return AttachResponse with:
  - SessionMetadata (rows, cols, shell_type, working_dir)
  - Scrollback for late-joiner sync (Vec&lt;Vec&lt;u8&gt;&gt;)
- Store connection state (attached_session, output_rx)

✅ **InputData** (lines 186-199)
- Validate client is attached
- Forward input to SessionManager.send_input()
- No response (fire-and-forget per Protocol spec)

✅ **ResizeRequest** (lines 200-213)
- Validate client is attached
- Call SessionManager.resize_session()
- No response

✅ **DetachRequest** (lines 214-232)
- Validate client is attached
- Call SessionManager.detach_client()
- Clear connection state
- No response

**Error Handling:**
- SessionNotFound → ErrorResponse
- "Not attached" validation for InputData/ResizeRequest/DetachRequest
- Invalid UUID parsing
- Graceful cleanup on disconnect
