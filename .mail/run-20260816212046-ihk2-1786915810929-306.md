## 3. How to Run

### Quick Start (Orchestrator - Recommended)
```powershell
cd scripts\soak-monitor

# Full 24-hour run
.\run-full-soak-test.ps1 -DurationHours 24

# Quick 1-hour validation (before 24h commit)
.\run-full-soak-test.ps1 -DurationHours 1

# With crash dump collection
.\run-full-soak-test.ps1 -DurationHours 24 -EnableCrashDumps
```

**What it does:**
1. Starts external monitor (PowerShell background job)
2. Sets `$env:SOAK_DURATION_HOURS` and runs `cargo test --release --test stability_24h`
3. Waits for both to finish
4. Runs evidence collection
5. Generates `SUMMARY.json` with final verdict

### Output Structure
```

└── run-20260816-143000/
    ├── SUMMARY.json                    # ← Final verdict (PASSED/FAILED)
    ├── soak-test-output.log            # ← Cargo test console output
    ├── external-monitor-output.log     # ← Monitor console output
    ├── external-metrics-*.csv          # ← 1440 rows of metrics (1/min)
    ├── alerts-*.log                    # ← All alerts with timestamps
    └── evidence-20260816-143000/       # ← Full forensics package
        ├── event-log-application.csv
        ├── event-log-system.csv
        ├── event-log-crashes.csv       # ← Empty = no crashes (good!)
```

## 5. Alerting Strategy

### Alert Philosophy
- **Alert BEFORE failure** → 8% memory growth warns before 10% test fail
- **Minimize false positives** → 50% handle growth is abnormal, 10% is noise
- **Survive the monitored process** → External monitor in separate PowerShell job

### When You'll Be Paged
**CRITICAL alerts (immediate action):**
- Process crashed (daemon died unexpectedly)
- Test failed (cargo test exit code ≠ 0)

**WARNING alerts (review next business day):**
- Memory growth >8% but <10% (trending toward failure)
- Handle count anomaly (potential leak)
- High sustained CPU (potential spin loop)

**INFO alerts (logged only):**
- Test started/completed
- Network state changes (expected for session create/kill)

```rust
if std::env::var("SOAK_TEST_MODE").is_ok() {

        .compact()
        .init();
```
