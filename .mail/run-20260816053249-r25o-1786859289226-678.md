## Code Logic Notes

**Glyph upload flow:**
1. Terminal grid has dirty cells
2. For each dirty cell:
   - Build `GlyphKey` from (char, bold, italic)
   - Look up in cache
   - **On miss:**
     - Rasterize via FontManager
     - Allocate atlas space (Guillotine)
     - Upload bitmap to GPU texture
     - Insert into cache
   - Use atlas coords for vertex texture coords

**Color handling:**
- VT parser emits `Color` struct (r, g, b)
- `color_to_rgba()` converts to `[f32; 4]` for shader
- Shader multiplies vertex color with glyph alpha

**Frame budget:**
- Glyph rasterization: <1ms per glyph (fontdue is fast)
- GPU upload: Async, doesn't block render
- Vertex build: <1ms for 80×24 grid
- Should easily hit 60 FPS target
