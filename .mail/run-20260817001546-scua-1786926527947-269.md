## Script Capabilities Overview

The provisioning script (`azure-vm-setup.ps1`) automates:

1. **Pre-flight checks:**
   - Verifies Azure CLI installed
   - Verifies Azure login + subscription
   - Displays account info for confirmation

2. **Resource provisioning:**
   - Creates resource group `monoterminal-phase1` in `eastus`
   - Provisions Standard_D4s_v5 VM with Windows 11 Pro
   - Configures public IP + NSG rule for RDP (port 3389)
   - Generates secure admin password (24 chars, mixed case + digits + symbols)

3. **Auto-shutdown:**
   - Configures Sunday 11 PM ET (03:00 UTC Monday) auto-shutdown
   - Prevents runaway costs if manual cleanup forgotten

4. **Handoff document generation:**
   - Creates `soak-test-vm-credentials-YYYYMMDD-HHMMSS.md`
   - Includes: RDP IP, username, password, VM specs, setup steps, execution command
   - Ready for encryption + delivery to performance-engineer

5. **Verification:**
   - Checks NSG rules (RDP port 3389 open)
   - Displays VM details + cost estimate
   - Provides next-step checklist
