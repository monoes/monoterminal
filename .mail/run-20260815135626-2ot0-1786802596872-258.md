## Required Implementation

### 1. Service Binary (`crates/master/src/service.rs`)

**Scope:**
- Windows Service API integration via `windows` crate
- Service control handler (SERVICE_CONTROL_STOP, SERVICE_CONTROL_SHUTDOWN, etc.)
- SCM (Service Control Manager) registration
- `--service` CLI flag (daemon mode vs. console mode)
- Proper startup/shutdown sequencing

**Service Specifications:**
- **Service Name:** `MonoTerminal`
- **Display Name:** `MONOTERMINAL Master Daemon`
- **Description:** `Persistent terminal multiplexer daemon`
- **Start Type:** Automatic
- **Account:** Local System
- **Binary Path:** `C:\Program Files\MONOTERMINAL\monoterminal.exe --service`

**Example Service Control Handler:**
```rust
use windows::Win32::System::Services::*;

fn service_main(args: Vec<String>) {
    let status_handle = RegisterServiceCtrlHandlerExW(
        w!("MonoTerminal"),
        Some(service_ctrl_handler),
        None
    ).unwrap();

    // Set service status to RUNNING
    set_service_status(status_handle, SERVICE_RUNNING);

    // Run main daemon loop
    run_daemon().await;

    // Set service status to STOPPED
    set_service_status(status_handle, SERVICE_STOPPED);
}

extern "system" fn service_ctrl_handler(
    control: u32,
    _event_type: u32,
    _event_data: *mut c_void,
    _context: *mut c_void,
) -> u32 {
    match control {
        SERVICE_CONTROL_STOP | SERVICE_CONTROL_SHUTDOWN => {
            shutdown_daemon();
            NO_ERROR
        }
        _ => NO_ERROR,
    }
}
```

### 2. CLI Flag Integration (`crates/master/src/main.rs`)

**Add `--service` flag:**
```rust
#[derive(Parser)]
struct Cli {
    /// Run as Windows Service (not console mode)
    #[arg(long)]
    service: bool,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let cli = Cli::parse();

    if cli.service {
        #[cfg(windows)]
        service::run_service()?;
        #[cfg(not(windows))]
        anyhow::bail!("--service flag is Windows-only");
    } else {
        // Console mode (existing behavior)
        run_console_mode().await?;
    }

    Ok(())
}
```

**Test File:** `crates/master/tests/service_test.rs`

**Example Test:**
```rust

fn test_service_lifecycle() {
    // Mock SCM interaction

    // Stop service

    assert_eq!(service.status(), SERVICE_STOPPED);
```

1. **Build release binary:**
   ```cmd
   cargo build --release --target x86_64-pc-windows-msvc
   ```

2. **Install as service (admin cmd):**
   ```cmd
   sc create MonoTerminal binPath="%CD%\target\x86_64-pc-windows-msvc\release\monoterminal.exe --service"
   ```

3. **Start service:**
   ```cmd
   sc start MonoTerminal
   ```

4. **Verify running:**
   - Check Task Manager → Services tab
   - Verify WebSocket server listening on port 5000
   - Connect web client to `ws://localhost:5000`

5. **Graceful shutdown:**
   ```cmd
   sc stop MonoTerminal
   ```
   - Verify: No orphaned processes
   - Verify: Active connections closed gracefully
   - Verify: Logs show clean shutdown

   ```cmd
   sc delete MonoTerminal
   ```
