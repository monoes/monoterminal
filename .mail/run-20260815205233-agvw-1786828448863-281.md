### 5. ✅ Planned Texture Upload Optimization (45 min)

**Bottleneck identified:** Synchronous texture upload blocks GPU

**Optimization strategy:**
1. **Batch uploads per frame** (not 1 glyph at a time)
   - Add `pending_uploads: Vec<GlyphUpload>` to Renderer
   - Queue uploads during render loop
   - Flush all uploads with ONE queue.write_texture() per glyph (but batched loop)

2. **Upload staging** to avoid blocking
   - Call flush_glyph_uploads() BEFORE surface.get_current_texture()
   - Keeps upload separate from render pass

3. **Cache miss handling** during rendering
   - If glyph not in cache, queue upload and skip rendering THIS frame
   - Render on NEXT frame when glyph is uploaded

**Frame budget analysis:**
- Total: 16.67ms (60 FPS)
- GPU render: 8ms target
- VSync: 5ms
- Headroom: ~3ms
- Risk: 1920 cells (80×24) × 0.1-0.5ms = 192-960ms if NOT batched ❌
- Solution: Batch uploads, only upload cache misses
