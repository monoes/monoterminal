## 1. Design Decisions from Last Session — ALL RESOLVED

### ✅ ConPTY Async I/O Patterns
**Status:** RESOLVED (blocking issue found and fixed by rust-engineer-pty)

**Issue Found:** ConPTY Windows API was using immediate ReadFile/WriteFile instead of proper async I/O with tokio integration.

**Resolution:** 
- Implemented proper poll_read/poll_write with tokio
- Added EOF detection (ERROR_NO_DATA, ERROR_PIPE_NOT_CONNECTED)
- Added FlushFileBuffers for low-latency input
- 4KB buffer size with 3 flush triggers (size/newline/timeout per SRS §3.1.4)

**Acceptance:** Immediate I/O acceptable for Phase 1 MVP. Overlapped I/O with IOCP deferred to Phase 2+ if performance metrics require it (documented in TASK-1-COMPLETION-REPORT.md).

### ✅ Session Lifecycle Management
**Status:** LOCKED IN per SRS §2.1.3

**State Machine Implemented:**
```
CREATE → RUNNING → TERMINATED
(DETACHED/REATTACHED deferred to Phase 2)
```

**Session Manager API (6 methods, all async):**
- create_session() — Spawn PTY, create session, start output loop
- attach_client() — Return snapshot with scrollback for late-joiner sync
- detach_client() — Remove client from fan-out list
- send_input() — Write to PTY with flush
- resize_session() — Call ResizePseudoConsole, update dimensions
- kill_session() — Terminate PTY, mark as Terminated

**Graceful Shutdown:** Phase 1 uses immediate TerminateProcess (Windows Service standard). SIGHUP→wait→SIGKILL escalation deferred to Phase 2 per SRS §2.1.3.

### ✅ Monomind Detection/Integration Strategy
**Status:** LOCKED IN per SRS §2.4.3

**Decision Ratified:** Embedded dashboard inside web client (ADR: §8.1.5), not a separate service.
- Same session JWT for auth (no separate credential file)
- No separate port (no port collision risk)
- Protocol messages: DashboardRequest/Response, HealthCheckRequest/Response, UpgradeRequest/Response

**Detection:** Walk upward from session `cwd` to find `.monomind/` directory (per-session detection per SRS requirement).

**Implementation:** `crates/monomind-bridge/src/detection.rs` + `health.rs` created.
