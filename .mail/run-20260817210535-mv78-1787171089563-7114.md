### Unit File Generation

**Dynamic template:**
```ini

Description=MONOTERMINAL Master Daemon
After=network.target

[Service]
Type=notify
ExecStart=/usr/local/bin/monoterminal-master --systemd
Restart=on-failure
RestartSec=5s

User=monoterminal
Group=monoterminal

WorkingDirectory={data_dir from task-53}

# Security hardening
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict

ReadWritePaths={data_dir} {log_dir}

# Resource limits
LimitNOFILE=65536
LimitNPROC=512

[Install]
WantedBy=multi-user.target
```
