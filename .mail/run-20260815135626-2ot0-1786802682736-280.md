#### 1. Health Check

**Request:**
```typescript
{
  message: {
    healthCheckRequest: {
      projectDir: sessionMetadata.workingDir  // From session state
    }
  }
}
```

**Response:**
```typescript
{
  healthCheckResponse: {
    installed: boolean,
    version: string,
    controlServerReachable: boolean,
    brokerRegistered: boolean,
    lastCheckTimestamp: number,  // Unix seconds
    issues: Array<{
      severity: IssueSeverity,  // INFO, WARNING, ERROR
      message: string,
      resolution: string
    }>
  }
}
```

#### 2. Upgrade

**Request:**
```typescript
{
  message: {
    upgradeRequest: {
      projectDir: sessionMetadata.workingDir,
      confirmed: true  // REQUIRED (user must confirm)
    }
  }
}
```

**Response:**
```typescript
{
  upgradeResponse: {
    success: boolean,
    oldVersion: string,
    newVersion: string,
    output: string  // Full CLI output
  }
}
```

#### 3. Detection (NEW - add to UI)

#### 4. Monitoring Stream (NEW - for org/agent status)
