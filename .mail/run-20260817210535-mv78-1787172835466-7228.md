### macOS-Specific Implementation

**Service User Creation (dscl):**
```rust
fn create_service_user() -> Result<()> {
    // Find next available system UID (200-399)
    let next_uid = find_next_system_uid()?;
    
    // Create user with dscl (Directory Service)
    dscl . -create /Users/_monoterminal
    dscl . -create /Users/_monoterminal UniqueID <uid>
    dscl . -create /Users/_monoterminal UserShell /usr/bin/false
    dscl . -create /Users/_monoterminal NFSHomeDirectory /var/empty
    
    // Create group
    dscl . -create /Groups/_monoterminal
    dscl . -create /Groups/_monoterminal PrimaryGroupID <uid>
}
```

**Key Features:**
- Underscore prefix (_monoterminal) for system accounts
- UID range 200-399 (macOS system account convention)
- Auto-finds next available UID
- Shell: /usr/bin/false (no login)
- Home: /var/empty (minimal security surface)

**UID Discovery:**
```rust
fn find_next_system_uid() -> Result<u32> {
    // List all users and their UIDs
    let output = dscl . -list /Users UniqueID
    
    // Parse UIDs in range 200-399
    let uids: Vec<u32> = parse_uids(output);
    
    // Find first gap
    for uid in 200..400 {
        if !uids.contains(&uid) {
            return Ok(uid);
        }
    }
}
```

### Service Status Checking

**service_status():**
```rust
pub fn service_status() -> Result<ServiceStatus> {
    // Check plist installed
    let installed = Path::new(PLIST_PATH).exists();
    
    // Check launchctl list
    let output = launchctl list com.monoterminal.master;
    let running = output.status.success();
    
    // Parse PID from output
    let pid = get_service_pid().ok();
    
    // launchd services are "enabled" if plist exists (RunAtLoad=true)
    let enabled = installed;
    
    Ok(ServiceStatus { installed, running, enabled, pid, message })
}
```

**launchctl Integration:**
```rust
fn get_service_pid() -> Result<u32> {
    let output = launchctl list com.monoterminal.master;
    
    // Parse: "12345\t0\tcom.monoterminal.master"
    let pid_str = stdout.lines().next()
        .and_then(|line| line.split_whitespace().next());
    
    if pid_str == "-" {
        bail!("Service not running");
    }
    
    Ok(pid_str.parse()?)
}
```
