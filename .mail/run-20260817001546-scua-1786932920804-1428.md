## Troubleshooting

**RDP Connection Refused:**
- Wait 2-3 minutes (VM may still be booting)
- Verify IP from credentials file
- Contact devops-lead if issue persists

**Rust/Git/protoc Install Fails:**
- Retry with: `winget install <package> --accept-source-agreements`
- Check internet connectivity
- Contact devops-lead if issue persists

**Build Fails:**
- Check error message
- Verify all dependencies installed (`cargo --version`, `protoc --version`)
- Contact rust-backend-lead for code issues

**Coverage Measurement Fails:**
- Ensure tarpaulin installed: `cargo install cargo-tarpaulin`
- Check disk space: `Get-PSDrive C`
- Contact devops-lead if tooling issue
