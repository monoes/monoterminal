## Memory Leak Fix: Technical Verification

**Root cause addressed:**
- **Before:** Background tasks held `Arc<RwLock<Session>>` → refcount never 0 → Session never dropped → PTY HANDLEs leaked
- **After:** `AbortOnDrop` in Session fields → tasks aborted on drop → Arc released → HANDLEs freed

**Drop sequence validated:**
1. `SessionManager::kill_session()` removes session from HashMap
2. Arc refcount → 0
3. `Session::Drop` runs (field drop order guaranteed)
4. `_output_task` drops → `AbortOnDrop::drop()` → task aborted
5. `_monomind_task` drops → `AbortOnDrop::drop()` → task aborted
6. Tasks release their Arc references
7. PTY backend drops → OS HANDLEs closed

**Tests confirm:**
- ✅ Tasks are cancelled when Session drops
- ✅ No reference cycles (Arc cleanup verified)
- ✅ Multiple sessions clean up correctly
- ✅ 100% task abort rate (0 tasks completed after 40 spawned)
