**3. Interactive Prompts** ✅

**Implementation:**
```rust
fn read_confirmation() -> bool {
    use std::io::{self, Write};

    let mut input = String::new();
    io::stdout().flush().expect("Failed to flush stdout");

    match io::stdin().read_line(&mut input) {
        Ok(_) => {
            let trimmed = input.trim().to_lowercase();
            trimmed == "y" || trimmed == "yes"
        }
        Err(_) => false,
    }
}
```

**User Flow (uninstall-service):**
1. Stop/disable/remove service files (Day 1 logic)
2. Prompt: "Remove data directory? [y/N]"
3. If --remove-data flag: skip prompt, auto-yes
4. If confirmed: rm -rf data_dir
5. Prompt: "Remove service user? [y/N]"
6. If --remove-user flag: skip prompt, auto-yes
7. If confirmed: userdel monoterminal (Linux only)

**Safety:**
- Defaults to preserve (N)
- Flags override prompts
- Service stops BEFORE data removal
- Platform-specific user deletion
