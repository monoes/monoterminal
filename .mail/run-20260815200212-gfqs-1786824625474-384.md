## Answers to Your Questions

### **1. Shader Texture Format: R8 (grayscale)**

**Decision**: `wgpu::TextureFormat::R8Unorm` for atlas

**Rationale**:
- Text rendering only needs alpha channel (grayscale)
- 4096×4096 R8 = 16 MB (vs. 64 MB for RGBA8)
- Shader samples R channel, uses as alpha for text color blending
- Standard for terminal text rendering

**Your bitmap format**: `Vec<u8>` R8 grayscale (exactly what fontdue outputs) ✅

**Shader fragment preview**:
```wgsl
@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    let alpha = textureSample(atlas, sampler, in.tex_coord).r;  // R8 → alpha
    return vec4<f32>(in.color.rgb, in.color.a * alpha);         // Multiply by text color
}
```

### **2. Glyph Size: Max 32×32px for Phase 1**

**Decision**: 32×32 pixel max per glyph

**Breakdown**:
