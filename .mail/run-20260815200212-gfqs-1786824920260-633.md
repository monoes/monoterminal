## Technical Coordination

**Latency Probe for Soak Test Monitor:**

devops-lead needs command to measure latency every 5 min during 24h run.

**Provide to devops-lead:**
```powershell
# Measure p95 latency (one sample)
function Measure-Latency {
    $result = & cargo bench --bench latency_e2e_lan -- --measurement-time 10 --sample-size 100 2>&1 | Select-String "p95"
    # Parse: "p95: 8.234ms"
    if ($result -match "p95:\s+([\d.]+)ms") {
        return [double]$Matches[1]
    }
    return $null
}
```

**Integration into soak-test-monitor.ps1:**
```powershell
# Inside devops-lead's monitoring loop
$timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$latencyP95 = Measure-Latency
$memoryMB = Get-ProcessMemory
$cpuPercent = Get-ProcessCPU

Log-Metrics -Timestamp $timestamp -LatencyP95 $latencyP95 -Memory $memoryMB -CPU $cpuPercent

# Output: CSV with timestamp, latency, memory, CPU
```
