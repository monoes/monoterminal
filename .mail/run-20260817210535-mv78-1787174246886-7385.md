## Package Format Comparison

| Feature | .deb | .rpm | Homebrew | Tarball |
|---------|------|------|----------|---------|
| Binary location | /usr/local/bin | /usr/bin | /usr/local/bin | /usr/local/bin |
| Service file | systemd | systemd | launchd | systemd or launchd |
| User creation | ✅ (monoterminal) | ✅ (monoterminal) | ✅ (_monoterminal) | ✅ (platform-specific) |
| Data directory | /var/lib/monoterminal | /var/lib/monoterminal | /Library/... | Platform-specific |
| Package manager | apt/dpkg | dnf/yum/rpm | brew | Manual |
| Upgrade handling | Preserves data | Preserves data | Preserves data | Manual |
| Removal options | remove / purge | remove | uninstall | Manual |
| Build automation | dpkg-buildpackage | rpmbuild | brew install | tar + scripts |
