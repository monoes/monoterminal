### 2. Design Features

✅ **Concurrent Execution:** All CLI commands run in parallel via `tokio::join!`  
✅ **Graceful Degradation:** Partial failures return empty data, never panic  
✅ **Fail-Loud:** All errors logged at WARN level via tracing  
✅ **Same Pattern as health.rs:** Consistent API across monomind-bridge  
✅ **6 Unit Tests:** Constructors, encoding, empty states
