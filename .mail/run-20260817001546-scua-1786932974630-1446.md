**RDP Connection Refused:**

**Environment Setup Fails:**
- Check if test-engineer-unit already set up (likely)

**Daemon Crashes During Smoke Test:**
- **This is a FAIL result** - report immediately
- Collect crash dumps from Event Viewer
- Check: `Get-EventLog -LogName Application -Source "Windows Error Reporting" -Newest 10`
- Report crash details to eng-director

**High Memory Growth (>1%):**
- **This is a FAIL result** - report immediately
- Likely indicates memory leak not fully fixed
- Check external-monitor.ps1 output for WS growth timeline
